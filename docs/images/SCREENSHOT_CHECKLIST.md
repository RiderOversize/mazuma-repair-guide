### 💡 วิธีการทำงานของระบบแทรกภาพอัตโนมัติ (Smart Auto-Embedding)
1. แคปภาพหน้าจอตามรายละเอียดด้านล่าง
2. ตั้งชื่อไฟล์ให้ตรงตามที่กำหนด (เช่น `01_login_view.png`)
3. นำไฟล์ภาพมาวางไว้ในโฟลเดอร์นี้: `docs/images/`
4. รันคำสั่งสร้างเอกสาร:
   ```bash
   node docs/generate_pdf.mjs
   ```
5. ระบบจะตรวจจับไฟล์ภาพโดยอัตโนมัติ และแปลงจาก **"บัตรระบุตำแหน่งรอภาพ (Blueprint Card)"** เป็น **"กรอบหน้าต่างแอปพลิเคชันเสมือนจริง (Device Window Frame)"** พร้อมแสดงแถบ URL, ปุ่มควบคุมสไตล์ macOS และคำบรรยายใต้ภาพโดยอัตโนมัติ

### 1. `01_login_view.png` — หน้าจอเข้าสู่ระบบหลัก
* **URL:** `http://localhost:3000/` (ขณะยังไม่ได้ล็อกอิน)
* **ไฟล์โค้ด:** `components/login-view.tsx`
* **สิ่งที่ต้องเห็นในภาพ:**
  - โลโก้ Mazuma เด่นชัด
  - การ์ดกระจก Glassmorphism โทนสีน้ำเงินพรีเมียม
  - ปุ่มสีเขียว **"เข้าสู่ระบบด้วย LINE"**
* **คำอธิบายใต้ภาพ:** *หน้าจอเข้าสู่ระบบหลัก แสดงโลโก้ Mazuma และปุ่มเชื่อมต่อบัญชี LINE Official*

### 2. `02_employee_bind_view.png` — หน้าจอผูกบัญชีพนักงานครั้งแรก (2FA Binding)
* **URL:** แสดงเมื่อล็อกอินด้วย LINE ครั้งแรกแล้วยังไม่เคยผูกรหัสพนักงาน
* **ไฟล์โค้ด:** `components/employee-bind-view.tsx`
* **สิ่งที่ต้องเห็นในภาพ:**
  - หัวข้อ "ยืนยันตัวตนพนักงาน / ผูกบัญชีความปลอดภัย"
  - ช่องกรอก **รหัสพนักงาน** (เช่น `MZ-001`)
  - ช่องกรอก **เบอร์โทรศัพท์ 10 หลัก** (เช่น `081-xxx-xxxx`)
  - ปุ่มกดยืนยันการผูกบัญชี
* **คำอธิบายใต้ภาพ:** *หน้าจอผูกบัญชีความปลอดภัยครั้งแรก (Two-Factor Identity Binding) ป้องกันการสวมสิทธิ์*

### 6. `07_feedback_escalation.png` — หน้าต่างประเมินผลการซ่อมและสายด่วนหัวหน้าช่าง
